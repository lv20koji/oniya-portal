# おにホーム 憲法（Constitution）

おにホーム（配信者おにや／o-228 の放送ポータル）の開発・運用における不変の原則。
仕様・計画・実装はすべてこの原則に従う。原則に反する変更は、まず本書を改訂してから行う。

## 原則

### I. 静的サイトのみ（Static Only）
- サイトは GitHub Pages で配信できる静的ファイル（HTML / CSS / JavaScript / JSON）のみで構成する。
- サーバーサイド処理、データベース、ログイン機能は持たない。
- 公開先は `lv20koji/oniya-portal` → `https://lv20koji.github.io/oniya-portal/`。

### II. APIキーを使わない（No API Keys）
- YouTube Data API、Twitch API など、キーや認証を要する API は使わない。
- 情報取得は公開フィード（YouTube RSS）と公開ページ（FollowBoard 等）の範囲に限る。
- 秘密情報（キー、トークン、パスワード）をリポジトリやサイトに含めてはならない。

### III. 追加課金ゼロ（No Extra Charges）
- 無料の範囲（GitHub Pages、公開フィード、既存の Muse スケジュール実行）だけで成り立たせる。
- 有料サービス・有料プランの契約を前提とする機能は採用しない。

### IV. コンテンツはオリジナル（Original Content Only）
- 参考にするのはカトホーム（web.katohome.jp）の**構成・機能**のみ。文言、デザイン、画像、データは一切流用しない。
- サイトの文言・デザインはすべて独自に作成する。放送タイトル等の事実情報は出典（公式チャンネル等）へのリンクと併せて扱う。
- サムネイルは YouTube 公式フィードが返す画像URLを参照表示するに留め、複製・再配布はしない。

### V. データは実在のみ（Real Data Only）
- broadcasts.json に載せる放送情報は、実際に取得できたものだけとする。推測・創作したタイトル、日時、URL を入れてはならない。
- 取れなかった項目（長さ、カテゴリ等）は欠落（null / 空）を許容し、でっち上げて埋めない。
- 各エントリに取得元（source）と取得時刻（fetchedAt）を記録し、サイトには全体の最終チェック日時（lastCheckedAt）を表示する。ライブ状態は「最終チェック時点」の情報として扱う。

### VI. 個人データは端末内（Personal Data Stays Local）
- 視聴ステータス（見た／あとで見る／途中）とメモは利用者のブラウザ localStorage にのみ保存し、外部送信しない。
- リポジトリに個人の視聴記録を含めない。引っ越しは利用者自身の JSON エクスポート／インポートで行う。

### VII. 更新は定期チェックで（Scheduled Human-in-the-loop Updates）
- データ更新は Muse が1日2回（朝・夜）公開情報を確認し、broadcasts.json を更新する方式とする。
- X（@oniyanogame）の確認はベストエフォートとし、確認できなかった回はその旨をデータ（xChecked: false）に記録する。確認できないことを理由に更新全体を失敗扱いにしない。
- 更新はマージ方式（既存エントリを消さず、新規分を追加）で行い、重複は video ID / URL で判定する。
